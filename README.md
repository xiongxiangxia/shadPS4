# 空中闪避实验与诊断 / Aerial evade experiment and diagnostics

## 中文

基于蓄枪和 3 倍镜头，研究天使闪避后的空中人类／恶魔闪避，并包含诊断记录。

适用游戏为 DmC Devil May Cry: Definitive Edition，CUSA01022，01.03。修改由 shadPS4 运行时加载，效果以实际游玩为准。

## English

Builds on charge compatibility and 3x camera, investigates human and demon aerial evades after angel evades, and includes diagnostics.

Target game: DmC Devil May Cry: Definitive Edition, CUSA01022, version 01.03. Changes are applied at runtime by shadPS4. In-game behavior requires verification.
