# 纯游玩版 / Gameplay edition

## 中文

包含蓄枪兼容、3 倍手动镜头和天使闪避后的人类／恶魔空中闪避调整。已移除持续诊断日志，保留启动状态和错误日志。

适用游戏为 DmC Devil May Cry: Definitive Edition，CUSA01022，01.03。修改由 shadPS4 运行时加载，效果以实际游玩为准。

## English

Includes charge compatibility, 3x manual camera speed, and human/demon aerial evade adjustments after angel evades. Continuous diagnostic logging is removed; startup and error messages remain.

Target game: DmC Devil May Cry: Definitive Edition, CUSA01022, version 01.03. Changes are applied at runtime by shadPS4. In-game behavior requires verification.
