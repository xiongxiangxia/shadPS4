# DmC 01.03 人类闪避实验版

适用游戏为 CUSA01022 / 01.03。与 3 倍纯游玩版使用相同的蓄力兼容和镜头逻辑。

1. 备份平时用的 shadPS4.exe，替换为诊断包里的 exe，启动但丁的关卡。
2. 天使闪避后松开天使键，仅点一次普通闪避。分别试一次直接接地面闪避，以及按原操作跳起来接普通空闪。观察按下后多久出招。
3. 从启动器的日志目录取本次游戏日志。确认里面有 `[DMC EVADE] Trace installed=true` 和 `input button=Evade`。默认 Info 日志级别即可。如果自定义过滤了 Input 类，把 Input 恢复到 Info。

第一下闪避自动开始五秒记录，无需 F9。每个游戏线程最多输出 384 条诊断记录。日志包含跳跃和闪避的按下事件、事件模式、动作图分支和条件结果、缓冲结果、相关 token 的创建和删除调用，以及动作启动时间。token 调用记录描述调用发生的时点。

角色与本次按键都在人类模式，且天使闪避留下的缓冲是空闲闪避图的阻挡条件时，实验版允许本次新按下的普通闪避先走原生选招。有既存输入排队时继续使用原生路径。游戏继续判断能否闪避、走地面还是空中动作，以及是否消耗空闪次数。`early_human_evade` 记录表示实验路径已触发。
